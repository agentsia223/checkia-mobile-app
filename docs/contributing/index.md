# Contributing

Contributions should follow the process in the repository [Contributing Guide](https://github.com/agentsia223/checkia-mobile-app/blob/main/CONTRIBUTING.md).

## Expectations

- Keep pull requests focused on one change.
- Add or update tests for behavior changes.
- Update documentation when setup, scripts, API expectations, or user-facing behavior changes.
- Include screenshots or recordings for visible UI changes.
- Keep private URLs, credentials, tokens, and signing material out of the repository.

## Required Checks

```bash
npm run typecheck
npm test
```

For UI changes, also run the app on Android, iOS, web, or Expo Go as relevant.
