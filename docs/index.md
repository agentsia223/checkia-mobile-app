# Check-IA Mobile Documentation

Check-IA Mobile is the Expo and React Native client for the [Check-IA](https://github.com/agentsia223/check_ia) fact-checking platform.

Use these docs to set up the mobile app, understand its API contract with the backend, and contribute changes that match the main Check-IA open-source standards.
