# Getting Started

Check-IA Mobile runs with Expo and connects to a Check-IA-compatible backend plus Supabase Auth.

## Requirements

- Node.js 20.19.4 or newer.
- npm 10 or newer.
- Git.
- Expo CLI through `npx expo`.
- Android Studio, Xcode, Expo Go, or another Expo-compatible test target.
- Watchman on macOS or Linux is recommended.

## Setup Flow

1. Clone the repository.
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env`.
4. Set backend and Supabase values.
5. Start Expo with `npm start`.

See [Mobile Setup](mobile.md) and [Environment Variables](environment.md) for details.
